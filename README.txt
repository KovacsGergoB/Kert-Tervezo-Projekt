KERT TERVEZŐ

A Kert tervező oldal lényege a növények összegyüjtése és a hozzájuk kellő hely megadása.

Megnyitás:
VSCode Live Server extension-el vagy megnyitni az index.html-t egy böngészőben.

TypeScript Fordítás:
Nodejs letöltése és TypeScript telepítése npm-en keresztül
VSCode-ban: Új Terminal megnyitása és "npx tsc kertts.ts" futtatása
Windows CMD: Cmd megnyitása, megnyitni a kert_tervezo mappát benne és "npx tsc kertts.ts" futtatni

Fő funkciók:
Egy listához új elemek hozzáadása, az új elem előnézete és az elemek kiírása AngularJS-el. A területek összesítése TypeScriptben.
